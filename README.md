## 环境说明

本机没有全局 npm，工具链已内置在 `wuguan/.toolchain/node/`（Node v22.13.0 官方发行版，含 npm 10）。

```bash
# 安装依赖（首次）
npm.cmd install

# 启动开发服务器（默认 http://localhost:5173）
npm.cmd run dev

# 构建产物
npm.cmd run build

# 预览构建产物
npm.cmd run preview
```

> `npm.cmd` 是项目根下的包装脚本：它会先 `cd` 到项目目录再调用 `wuguan\.toolchain\node\npm.cmd`（系统没有全局 npm，工具链已内置）。

## 与需求文档的对照

- 技能 id 与 §3 一一对应（foraging / fishing / hunting / excavation / farming / cooking / baking / preserving / brewing / spiceMixing / craftsmithing / knife / heatControl / flavorArtistry / plating / tasteAcumen / spiritSummoning / gastronomy / preservation / exploration）
- 背包/仓库使用 `{ itemId: quantity }` 对象形式（文档示例为数组 `[{id, quantity}]`），便于 Vue 响应式与查找，结构语义一致
- 存档当前存于 LocalStorage，`SaveManager` 接口预留 IndexedDB 切换点（§10.1 主存储为 IndexedDB，后续迭代）

### 🔒 生成器安全（v1.6.2 新增）

**核心结论：产物是「活数据」——游戏读的就是它；生成器输出只是「若今天重印会印成什么样」。两者不一致时，重跑 = 改掉游戏内容，而不是「把过期文件更新成正确内容」。**

- **输出目录统一**：13 个生成器默认写 `src/game/data`，设 `GEN_OUT_DIR` 可改写（用于无损比对）。此前有 6 个因 `scripts/` 目录三分而写向不存在的 `scripts/src/…`，已修正。
- **5 个生成器已上硬门禁**（`gen_exploration_targets` / `gen_expansion` / `gen_expansion2` / `gen_quests` / `gen_season_gear`）：其产物属「已固定」冻结数据，实测重跑会改写内容（补回 10 条保鲜配方、换掉 452 个任务中 365 个的目标、改写 20 个赛季的任务、换掉赛季奖励物品、改 79 个探索目标名称），因此**默认拒绝执行**，确需重跑要显式 `ALLOW_FROZEN_REGEN=1`。
- **审计常驻**：`scripts/ci/gen_drift_audit.mjs` 把每个生成器跑进**临时目录**与仓库产物比对（全程只读、哈希自证），逐条打印「重跑会改什么」。
- 完整门禁范围、实测差异与事故记录见 `AGENTS.md` 的「冻结数据生成器门禁」；**任何「改完生成器就重跑」的说法自 v1.6.2 起作废**。

- **解锁节奏**（`balance_sim.mjs` 真实引擎模拟）：**推荐等级对局胜率 ≈100%**（白板+食物 vs 学徒厨师 100%、铜装 vs L小吃摊主 100%、铁装 vs 川菜师傅 100%、铁装 vs BOSS 面条之王 100%）。
  ⚠️ **该脚本的「解锁节奏」段用的是「白板起步、不换装备、只打 ≤ 当前等级+5 的对手」的机器人**——它会在对决 24 级左右撞墙（实测 12000 场内 10955→**对决 10 约 3.7k 场、20 约 8.1k 场**、25 级起未达成；战败 4235/12000），因此**它衡量的是「最保守玩法的下限」，不是正常玩家的节奏**（正常玩家会换装备/吃增益/打推荐等级）。历史上这里曾写过一组「10→25 场」的旧数字（2026-09-10 的旧模型口径），2026-09-13 全量走查时按实测更新，并用 v1.10.1 代码 A/B 确认为**模型口径差异、非曲线回归**（v1.10.1 = 3745 场 / v2.1.1 = 3772 场，差值来自战斗随机）
- **材料等级平衡**（`recipeBalance.js`）：材料获取等级 ≤ 物品等级 + 5；食谱类抬配方等级而不删主料；保鲜/锻造/食灵移除超纲材料；高频通用食材自动替换为「嫩X」低阶可采集版本
- **装备数值**（`itemBalance.js`）：主属性按槽位 center（该套等级）赋值，保证单调递增无倒挂；食物/饮品同级保留 ±30% 梯度、跨段严格单调
- **价值平衡**（`valueBalance.js`）：可采集材料与配方产物的价值夹到「获取等级 × 曲线」的 ±30% 带
- **经验平衡**（`xpBalance.js`）：采集基准 `10+5L`、制作基准 `25+13L`，只抬不降（消除高等级给低经验的倒挂）
